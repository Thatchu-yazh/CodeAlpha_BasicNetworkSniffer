\# CodeAlpha Cyber Security Internship – Task 1  

\# Basic Network Sniffer using Python



\---



\## 📌 Project Overview:

The Basic Network Sniffer is a Python-based cybersecurity project developed as part of the CodeAlpha Cyber Security Internship Program.  

This tool captures live network packets flowing through the system and analyzes essential packet details such as source IP address, destination IP address, protocol number, and packet size.



This project demonstrates foundational knowledge of:

\- Network Traffic Monitoring  

\- Packet Analysis  

\- IP Address Inspection  

\- Protocol Identification  

\- Ethical Cybersecurity Practices  



\---



\## 🎯 Objective:

To understand how data packets travel across a network and to build a basic packet analysis tool that helps monitor communication between devices.



\---



\## 🚀 Key Features:

✔ Captures live network packets in real time  

✔ Displays Source IP Address  

✔ Displays Destination IP Address  

✔ Identifies Protocol Number  

✔ Calculates Packet Length  

✔ Helps understand packet structure and traffic flow
